# receipts

A native iOS news reader for people who don't trust the news.

Every story arrives as a case on a cork board: source pins, evidence dossiers, connecting strings, reliability stamps. The hero feature — **Deep Check** — runs a visible, animated investigation in front of you: pins drop as sources are reviewed, red strings draw between corroborating reports, a verdict stamp slams when it's done. You watch the work happen. The trust mechanic is the workflow itself.

> *"Quiet day on the beat. Allegedly."*

Internally codenamed **THE CRIME BOARD** (the cork-board / detective system is the design metaphor — see PRODUCT.md and DESIGN.md). The public brand is `receipts`.
